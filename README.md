# Cloud Resource Management Platform

A cloud resource provisioning and monitoring platform built with React, Express, and Prisma. It allows users to provision virtual machines, databases, and storage instances while tracking real-time telemetry and generating automated billing statements.

## Setup

### Backend
1. cd backend
2. npm install
3. npx prisma db push
4. node seed.js
5. npm start

### Frontend
1. cd frontend
2. npm install
3. npm run dev
